# Absher Chatbot Guidelines

## Purpose
This document provides guidelines for developing and maintaining the Absher Chatbot application.

## Component Structure

### Components
- **figma/**: Contains Figma-related components
  - `ImageWithFallback.tsx`: Image component with fallback support

- **ui/**: Contains UI components
  - `AbsherConciergeDrawer.tsx`: Drawer component for concierge services
  - `AbsherDashboard.tsx`: Main dashboard component
  - `FloatingButton.tsx`: Floating action button component
  - `PortfolioDrawer.tsx`: Portfolio drawer component
  - `PortfolioEditor.tsx`: Portfolio editing component

## Coding Standards

### TypeScript
- Use TypeScript for all component files
- Define proper interfaces for component props
- Use functional components with React hooks

### Styling
- Use CSS classes for styling
- Follow consistent naming conventions
- Keep styles in the `styles/` folder

## Best Practices
1. Keep components modular and reusable
2. Use proper type definitions
3. Follow React best practices
4. Write clean, maintainable code
5. Document complex logic

## Contributing
When adding new components or features:
1. Follow the existing folder structure
2. Create proper TypeScript interfaces
3. Add appropriate documentation
4. Test thoroughly before committing
